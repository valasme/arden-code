# Fonts used by the brand pipeline

**Lora Regular** (Latin subset), from `@fontsource/lora` 5.3.0. It is only used at build time to turn
the words "Arden Code" into outlines, so it is not shipped with the app.

Lora is licensed under the SIL Open Font License 1.1: see [OFL.txt](OFL.txt).
The generated logo files contain outlines of the letters, not the font itself.
