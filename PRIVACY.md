# Privacy

**Arden Code collects nothing.** There is no telemetry, no analytics and no crash uploading.

- **Network:** the only automatic request is the update check to GitHub Releases, which shows your IP
  address to GitHub. You can turn it off in Settings → General.
- **Everything else is your action,** such as opening a link in your browser.
- **Your data stays on your machine.** Settings live in `%APPDATA%\io.github.valasme.arden` and logs in
  `%LOCALAPPDATA%\io.github.valasme.arden`.
- **Logs never leave the machine.** Exporting diagnostics makes a local zip file, and you decide whether to share it.
  Logs strip your user folder path, tokens and email addresses.
- **Sign-in.** Claude Code and Codex sign in through their own command-line tools. Arden Code never sees
  your credentials.

Arden Code is not affiliated with Anthropic or OpenAI. What those services do with your data is governed by their own terms.
